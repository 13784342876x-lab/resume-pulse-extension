# 简历脉冲 · Chrome / Edge 插件 v0.6.22

## 开发与版本发布

v0.6.15：工作经历新增所属行业、工作国家、省份和城市字段；可从已有工作地区拆分明确的省市（含直辖市），不使用本人籍贯或居住地补齐。过滤器弹窗类地区控件仍需实际页面验证。

v0.6.14：每条工作/实习经历新增所在部门，支持所在部门、所属部门、任职部门和部门名称标签；缺少部门资料时留空，不借用岗位或公司名。

v0.6.13：通用下拉流程改为关联弹层→选择→验证控件值→关闭弹层；点击选项不再直接计为成功。无法关闭弹层时暂停后续下拉项，避免窗口堆叠。无网站域名专用判断；已测试不同组件和延迟/失败流程，交通银行实际简历页面尚未验证，复杂级联仍可能需要手选。

v0.6.12：扩充户口性质选项；新增绩点制、研究方向及课题、学历与学位证书编号、家庭成员地址。父亲/母亲分区按标题选择成员，多列表格标签不再跨列拼接。证书编号缺值时留空，禁止使用学历名称。模拟测试不代表已验证截图网站。

v0.6.11：优先使用字段直接标签和紧邻表格标签，防止 profile 字段 ID、同行其他列、邻近说明干扰基本信息匹配。出生日期增加非日期内容拦截。增加简介/生日/籍贯/生源地混合表格回归测试；尚未在用户截图网站实测。

v0.6.10：扩展 iView、Next、Semi、Arco 和 ARIA 下拉控件识别与鼠标触发；没有待重试原生控件时停止重复扫描。高亮增加内侧绿框，完成后保留 12 秒。结果显示扫描数、未识别数、未填入数与耗时；尚未在用户照片对应的网站实测。

v0.6.9：英语成绩优先使用外语档案的考试分数；普通“成绩”不再当作 GPA。缺少或不能唯一确定外语成绩时留空，避免借用教育绩点。

v0.6.8：教育经历明确显示“学习形式（教育方式）”，增加业余、脱产、开放教育选项；沿用原 studyForm 数据，不重复建字段。

v0.6.7：缓存每轮扫描的标签和控件列表，减少重复克隆及可见性检查；成功填写的普通输入框、下拉组件及单选项显示绿色边框，输入框和下拉框在整轮完成后继续高亮 8 秒。保留动态联动下拉的重试扫描，未成功选择的控件不显示成功高亮。

v0.6.6：项目经历接入整卡记录匹配，补齐所在单位、团队规模和个人项目职责。旧 detail 内容继续作为项目介绍使用，不推测个人职责；支持同组起止时间和新增第二条项目。模拟测试不代替实际招聘网站验证。

v0.6.5：补充教育的学历参与、专升本、双学位、学生干部、专业分类路径，以及实习的单位性质、工作性质、地区和补充说明。教育/工作卡片按整条记录匹配，支持同页新增和保存后复用空编辑器；已选学历参与匹配。未提供的新字段不推测填值。顺序状态保存在当前页面，刷新页面会重置。招聘网站自定义按钮及日期组件仍需逐项复核。

v0.6.4：修复嵌套卡片布局中家庭资料误用本人信息的问题。优先按卡片已选关系匹配家庭成员，支持工作单位及职务合并字段；关系未知、重复或资料缺失时跳过，不使用本人信息补齐。已通过模拟页面回归测试，仍需在实际招聘页面复核。

需要 Node.js 24 与 PowerShell 7（`pwsh`）。

```sh
npm ci
npm run check
npm run package
```

安装包生成在 `dist/`，只包含扩展运行文件。测试使用虚构个人资料；原始简历、临时图片、OCR 缓存和 `node_modules` 不纳入 Git。

每次改动后提交并推送 `main`，GitHub Actions 会自动测试和打包。发布新版本时：

```sh
npm run version:set -- 0.6.4
npm run check
git add .
git commit -m "Release v0.6.4"
git tag v0.6.4
git push origin main
git push origin v0.6.4
```

将示例版本号替换为本次版本。版本标签触发测试，通过后自动创建 GitHub Release 并附上 ZIP 安装包。普通代码推送也可在 Actions 中下载测试包。

GitHub 发布安装包不会让“加载已解压”安装的扩展自动升级；用户仍需将新版覆盖原目录并重新加载。若需要浏览器自动升级，需要另行发布到浏览器扩展商店。

日期按年、月、日分别精确选择；导入生日保留完整日期，只有年月的资料不会自动补为 1 日。联动下拉框重新扫描等待加载的控件，按显示文字匹配省市和民族。增加 ARIA、常见 Element / Ant Design 下拉组件的选项点击与搜索支持。已通过模拟控件回归测试；不同招聘网站的组件仍可能需要单独适配。

逐条录入家庭成员时，同一页面会记住已填写成员，清空或新建成员表单后继续下一位；重复点击同一条不会推进。刷新页面后可在悬浮面板的“逐条填写家庭成员”下拉框指定成员。修改已有记录时，选择成员并勾选覆盖。请先备份 JSON，再将新版文件解压覆盖原扩展目录，在扩展管理页重新加载并刷新招聘页；无需卸载扩展。

一款本地优先的网申表单填写插件，面向国企、事业单位以及旧式招聘系统。招聘页面加载完成后会自动显示悬浮圆形按钮与助手面板；收起面板后按钮仍保留在页面右侧。点击“一键填写”后识别并填入资料，但永远不会自动提交。

## 安装

1. 解压发布包。
2. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 开启“开发者模式”。
4. 选择“加载已解压的扩展程序”，选择本目录。
5. 首次点击插件图标，在悬浮助手中进入“管理简历资料”；可手工建档，也可导入 PDF、DOCX、PNG/JPG/WEBP、TXT、Markdown 或 JSON。
6. 回到并刷新招聘页，悬浮助手会自动出现；点击“一键填写当前页面”。

## 权限说明

- `storage`：仅在当前浏览器保存个人档案。
- `activeTab`：只有点击插件时才临时访问当前标签页。
- `scripting`：把资料填入当前页面的表单。
- 网站访问权限：用于在招聘页面加载后自动显示助手，并处理内嵌招聘表单。助手只在 URL 或页面内容符合招聘/简历特征时自动出现。

插件需要在招聘页面注入悬浮助手，因此声明网页访问权限；但不会读取密码，也不会点击提交按钮。只有你主动选择的简历文件会被读取，身份证号等敏感字段为可选项。

简历解析使用随插件打包的 PDF.js、Mammoth 与 Tesseract.js，在浏览器本机完成，内容不会上传服务器。图片型或扫描型 PDF 没有文字层时，会自动启动离线中英文 OCR；也可以直接导入 PNG、JPG 或 WEBP 简历图片。首次识别通常比普通 PDF 慢。

PDF 会先根据每个文字块在页面上的坐标重建阅读顺序，再按照“教育经历、工作/实习经历、技能/证书”等分区解析；不会再把学校行和专业/学历行误判成两段教育。

## 当前覆盖

- 基本与户籍：姓名、曾用名、性别、生日、出生地、民族、国籍、政治面貌、身高体重、婚姻、健康、证件、户口、北京落户需求、籍贯、生源地、人员类别、档案所在地。
- 联系与地址：手机、邮箱、现居住地 / 常住地址 / 通信地址（统一保存）、邮编、主页、紧急联系人、微信号。
- 多段教育：按最高学历到高中保存，支持调整顺序。
- 完整教育字段：院系、专业类别、学校地区与类型、学历状态、学制、起止日期、教育方式、招生类别、绩点、专业排名和联合培养。“是否统招”不再重复保存，统一由“招生类别=统招”表达。
- 奖惩、竞赛、证书、论文、专著、专利。
- 家庭成员：关系、姓名、出生年月、年龄、政治面貌、工作单位、职务、联系电话；关系与政治面貌使用下拉选择。
- 多段工作及实习经历、外语能力。
- 校园经历：学校 / 组织、职务、起止时间和主要成果。
- 项目经历：项目名称、本人角色、起止时间和项目成果。
- 职业状态与自我评价：保留就业状态和个人优势；不再重复维护最近公司、最近职位、工作起止时间、工作描述和技能关键词。
- 国企专项长文本：个人情况报告、能力说明、谋职方式、特别提示。
- 自定义字段：为单位特有字段补充名称和内容。
- 多人档案：可新建、删除、切换多份简历；悬浮面板内可直接选择当前填写人。
- 省市区选择：出生地、户口所在地、籍贯、生源地和学校所在地使用离线三级联动下拉框；现居住地 / 常住地址 / 通信地址改为一个手工填写的完整地址。
- 日期选择：出生日期、政治面貌时间和教育起止日期使用年/月/日下拉框。
- 国籍、健康状况、政治面貌、家庭成员关系等标准枚举字段使用下拉选择。

## 适配说明

- 能识别字段名与控件分离的旧式 `table` 表单，以及常见 `label`、ARIA、占位符和组件容器。
- 同一次填写会尝试所有可访问的 iframe。
- 地址等联动下拉框会分三轮填写，给省、市、区选项留出刷新时间。
- 旧式“英语能力”双下拉框会按“考试类型 + 成绩 / 等级”分别填写；家庭成员会优先按“父亲 / 母亲”等角色匹配，避免把称谓填入姓名或年龄。
- 已有内容不会被覆盖；照片、简历附件和诚信承诺会提示手动完成。
- 如需用另一份档案测试已有页面，可在悬浮面板勾选“覆盖页面已有内容”；文件上传和诚信承诺仍不会覆盖。

不同招聘网站的组件可能需要针对性适配。遇到未识别字段时，保留页面截图与字段名称即可继续增加规则。
